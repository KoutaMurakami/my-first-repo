## 開発状況についての注意(2026年10月時点)

このリポジトリは**開発途中**のFlutterアプリ(筋トレ・食事・体重管理)です。

- **食品の栄養データは動作確認用の概算値**です。文部科学省「日本食品標準成分表」から正式に取り込んだものではありません(`app/lib/database/food_seed.dart`)。栄養素も現時点では8種類(エネルギー・PFC・カルシウム・ビタミンC・鉄・食物繊維)のみです。正式な成分表データへの置き換えは今後の予定です。
- AI機能(食事アドバイス・メニュー提案・写真認識)、ログイン/クラウド同期は未実装です。
- 設計の経緯は `docs/` を参照してください(要件定義・DB設計・技術選定・UI設計)。
