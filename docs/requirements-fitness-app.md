# フィットネス管理アプリ 要件定義

筋トレ記録・食事管理・体重/活動管理をAIでサポートするスマートフォンアプリの要件定義書。

- 作成日: 2026年8月
- ステータス: ベータ版開発に向けた要件定義フェーズ完了

## 1. 全体方針

| 項目 | 内容 |
|------|------|
| プラットフォーム | スマートフォンアプリのみ(デスクトップは無し) |
| 対応OS | iOS / Android 両対応。最低ラインは iOS |
| ユーザー | まずは開発者本人によるベータ運用 → 将来的に一般公開 |
| オフライン対応 | 必須。ローカルファースト＋クラウド同期 |
| 開発方針 | 難易度の低い機能から実装し、AI系の高難度機能は後のフェーズに回す |
| Git運用 | `main` を土台にし、機能ごとに `feature/xxx` ブランチで開発。開発過程をGitHub履歴として残す |
| UI/デザイン | 別途 ClaudeCodeDesign 側で対応(本ドキュメントの対象外) |

## 2. 機能要件

### 2.1 筋トレ記録(最重要機能)

- **種目入力**: リストからの選択、および手入力の両方に対応
- **種目ライブラリ**:
  - 部位別に分類、フィルター・検索機能を用意
  - 初期リリースはメジャー種目のみ。マニアックな種目(アーノルドプレス、カーフレイズ等)は将来的に拡充
  - (将来)AIによる動画・イラスト解説
- **記録項目**: 重量、Rep数、セット数を基本とする
- **セット形式**: 通常セットに加え、ドロップセット・ピラミッドセット・ジャイアントセット等の複雑なセット構成に対応できるデータ構造とする
- **レストタイマー**: セット間の休憩時間を計測する機能
- **前回比較**: 同じ種目を再度行った際、前回記録との比較を表示(ボタン操作 or AIによる提示)
- **マイトレリスト**: よく使う種目・ルーティンを登録し、毎回の入力の手間を減らす
- **初心者サポート(AI)**: ユーザーの目的や志向に合わせておすすめの種目・メニューを提案
- **(将来)フォームチェック**: カメラ撮影によるフォーム評価。骨格推定AIが必要な高難度機能のため大幅に後回し

### 2.2 食事管理

- **記録方法**: カメラでの撮影→AIによる自動認識が理想形。手入力にも対応
- **手入力UX**: 食品名を検索し候補から選択できるようにする(栄養成分の手入力は必須としない)
- **記録する栄養素**: カロリーだけでなく、PFC(タンパク質・脂質・炭水化物)、ミネラル、ビタミンまで網羅
- **記録タイミング**: 朝食/昼食/夕食のような固定枠を設けず、食べたタイミングでミール単位に自由記録
- **(将来)AIアドバイス**: 記録した栄養データをもとに、AIが食事内容の総評・改善アドバイスを行う(あすけん的機能)
- **(将来・一般公開後)似た属性ユーザーの食事参考**: 匿名化を前提に、似た目的・体型のユーザーの食事を参考にできる機能。一定のユーザー数が必要なため一般公開後のフェーズ

### 2.3 体重・活動管理

- **記録項目**: 体重、体脂肪率、筋肉量
- **活動量**: 歩数、日常活動量
- **消費カロリー自動算出(本アプリの核となる機能)**: 筋トレ記録(種目・時間・強度)と体重データを基に、METsベースで消費カロリーを自動計算する。そのため筋トレ記録側のデータ構造は、この計算に使える情報(種目種別・時間・強度)を保持できるように設計する
- **進捗写真**: 身体を撮影し、時系列で比較できる機能
- **グラフ表示**: 体重・活動量等の推移をグラフで確認できる機能

## 3. 認証・通知

- **認証**: メールアドレス＋パスワードによるログイン。二段階認証は不要(体組成データは金融情報ほどの機密性を要さず、2FAの手間は継続利用の妨げになりうるため)
- **通知**: リマインド等はすべてユーザーが任意に設定(強制通知は行わない)

## 4. ビジネス・非機能要件

- **収益化**: フリーミアムモデル(基本無料＋一部機能を有料 または 月額サブスクリプション)。広告表示・買い切り販売は採用しない
- **対応言語**: 日本語・英語の2言語(全言語対応は行わない)
- **バックアップ/データ同期**: クラウド同期によるバックアップを実装する(機種変更等でのデータ消失を防ぐため)
- **データエクスポート**: 実装しない(クラウド同期でデータ消失リスクに対応できるため、別機能としてのエクスポートは不要と判断)
- **利用規約・プライバシーポリシー**: 現時点の要件定義スコープ外だが、一般公開前には必須。リリースチェックリストに含めること

## 5. 実装優先度の目安

| フェーズ | 内容 |
|----------|------|
| 易(初期) | 筋トレ手入力/リスト選択・部位分類、体重/活動量記録・グラフ、進捗写真、マイトレリスト、レストタイマー |
| 中 | 複雑なセット構成、食事の手入力+食品検索、前回比較、認証・クラウド同期、METs消費カロリー計算の土台 |
| 難(AI系・後期) | カメラ食事認識、AI食事アドバイス、AI初心者向けメニュー提案、AIフォームチェック、似た属性ユーザーの食事参考 |

## 6. 今回のスコープ外(将来検討)

- カメラによるフォームチェック(AI骨格推定)の本実装
- 似た属性ユーザーとの食事比較機能の本実装
- 利用規約・プライバシーポリシーの文面作成
- 収益化における無料/有料機能の詳細な線引き
