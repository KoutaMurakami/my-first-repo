## ダーティーチートプロトコル

### 実施基準

| 条件 | 内容 |
|------|------|
| 停滞判定 | ウエスト周囲径が**2週間以上変化しない**場合 |
| 予防的実施 | 停滞なくとも**3〜4週に1回** |
| 最適曜日 | **土曜日**（週最大ボリュームのトレ後 → 余剰カロリーが筋グリコーゲンへ優先的に流れる） |

### ルール

| 項目 | 内容 |
|------|------|
| 食事制限 | **なし**（好きなものを食べる） |
| 期間 | **1日のみ** |
| アルコール | 飲み会と重なる場合はその日をチートにカウント可 |
| 翌朝体重 | +1〜3kgは正常（グリコーゲン・水分の増加）。測定しても動揺しないこと |
| 翌日 | 即プラン復帰。**2日以上連続は不可** |

### 停滞時フロー

```
ウエスト2週間変化なし
　↓
土曜にダーティーチート（1日）
　↓
翌日（日曜）から即プラン復帰
　↓
翌週から再び減少
```

## 進捗管理

| 測定項目 | 頻度 | 方法・ポイント |
|---------|------|-------------|
| 体重 | 毎朝（起床後・排泄後） | **週平均**で判断。単日の増減±2kgは誤差 |
| ウエスト周囲径 | 週1回（日曜朝） | へそ位置。**最も信頼できる脂肪減少の指標** |
| 体型写真 | 2週に1回 | 同時間・同照明・同ポーズ |
| トレーニング重量 | 毎回記録 | 重量・レップ数の低下は筋分解のサイン |

> クレアチン継続中のため体重には1〜2kg分の水分が含まれる。  
> ウエスト周囲径と写真を主軸に進捗判断すること。
